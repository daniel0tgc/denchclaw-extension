Current State

Everything is installed and configured. The only remaining blocker is:

🔴 Bug 1 — Protocol mismatch (BLOCKING)

File: apps/web/lib/agent-runner.ts
Lines: ~463-464
Problem: The buildConnectParams function returns hardcoded minProtocol: 3, maxProtocol: 3 but the OpenClaw gateway 2026.5.12 requires protocol version 4.

Gateway log proof:

"minProtocol":3,"maxProtocol":3,"expectedProtocol":4,"minimumProbeProtocol":4

Fix:

sed -i '' 's/minProtocol: 3,/minProtocol: 4,/' apps/web/lib/agent-runner.ts
sed -i '' 's/maxProtocol: 3,/maxProtocol: 4,/' apps/web/lib/agent-runner.ts

🟡 Bug 2 — DuckDB schema missing icon column (non-blocking, b2b-crm)

Error: Table "objects" does not have a column with name "icon"
Fix: Delete the old DuckDB file so it reinitializes:

rm -f ~/.openclaw-dench/workspace/workspace-cloud.duckdb

openclaw.json Config

The config at ~/.openclaw-dench/openclaw.json is auto-generated by pnpm dev on first run after wiping ~/.openclaw-dench. Do NOT manually create it before running pnpm dev — let the bootstrap wizard create it.

During the setup wizard:





Config handling → Reset before setup



Reset scope → Config only



OpenClaw updates → Yes (update if prompted)



Gateway service → Restart (if asked)

After setup, add b2b-crm config by running:

node -e "
const fs = require('fs');
const path = require('path');
const configPath = path.join(process.env.HOME, '.openclaw-dench/openclaw.json');
const config = JSON.parse(fs.readFileSync(configPath, 'utf-8'));
const key = require('crypto').randomBytes(32).toString('base64');
config.plugins = config.plugins || {};
config.plugins.entries = config.plugins.entries || {};
config.plugins.entries['b2b-crm'] = config.plugins.entries['b2b-crm'] || {};
config.plugins.entries['b2b-crm'].enabled = true;
config.plugins.entries['b2b-crm'].config = {
  tenantId: 'default',
  syncIntervalMs: 30000,
  encryptionKey: key
};
fs.writeFileSync(configPath, JSON.stringify(config, null, 2));
console.log('b2b-crm config written. Encryption key:', key);
"

What NOT To Do





Do NOT manually edit ~/.openclaw-dench/openclaw.json to add "b2b-crm" as a top-level key under plugins — it must go under plugins.entries["b2b-crm"].config



Do NOT run pnpm web:build before pnpm build — the web prepack step needs dist/flatten-standalone-deps.js which only exists after pnpm build



Do NOT paste JSON directly into the terminal — use cat > file << 'EOF' or the Node.js script above



Do NOT run dench login — the DENCH_API_KEY env var is sufficient



Do NOT look at browser console errors — they are all harmless noise. Only the terminal and ~/.openclaw-dench/logs/ matter
